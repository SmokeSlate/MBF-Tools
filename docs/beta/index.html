Installing and updating

Install the APK on your Quest using the package installer. A properly signed beta updates your existing MBF Tools installation and keeps its data. Do not uninstall if Android rejects the update; report the error instead.

Beta builds use the beta update channel. Use the in-app update check to get newer beta releases. Stable installations stay on the stable channel.

Returning to an older stable version may require uninstalling and losing app data. Wait for a newer stable release if you want to avoid that.
